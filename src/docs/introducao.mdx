# Mellow UI

> **Página de exemplo.** Troque este conteúdo pelo texto real da introdução quando chegar a hora. A ideia aqui é só mostrar a estrutura (título, seções, blocos de texto) que essa página deve ter.

Design System em React + TypeScript: componentes de interface construídos com Tailwind CSS puro, documentados e testados via Storybook.

A arquitetura toma como referência conceitos consolidados no ecossistema React (padrão `asChild`/Slot), mas é uma implementação própria — não depende de outras bibliotecas de componentes. A paleta de cor de marca, a escala de sombra e a fonte padrão ficam fixadas em `@theme` (Tailwind); todo o resto de layout e tipografia usa a escala nativa do Tailwind direto nos componentes.

## Nesta documentação

- **Instalação** — como adicionar o Mellow UI a um projeto.
- **Cores** — a paleta de tokens de cor (accents e neutros) e como funciona o tema claro/escuro.
- **Tipografia** — a escala de fontes, pesos e alturas de linha.
- **Espaçamento** — a escala de espaçamento usada em padding, margin e gap.
- **Acessibilidade** — os princípios que guiam a construção dos componentes.
